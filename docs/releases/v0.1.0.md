# v0.1.0 - The AI Runtime Foundation

We are thrilled to announce the initial release of **Agent Runtime Core (`@agent-runtime/core`)**, an open-source framework designed to bring event-driven architecture to generative AI applications.

## 🌟 The Vision
Building AI applications shouldn't mean abandoning traditional software engineering best practices. We built this framework to bridge the gap between deterministic business systems (like ERPs, CRMs, and ticketing systems) and probabilistic AI models. 

Instead of writing massive, monolithic prompt chains, this framework allows you to build **autonomous agents** that react to standard business **events** via a highly scalable pub/sub architecture.

## 🚀 Key Features in v0.1.0

- **Unified `Runtime`**: A single entry point to orchestrate your entire AI ecosystem.
- **`EventBus`**: An in-memory pub/sub engine that routes events to agents and pipelines.
- **Agnostic `AIProvider`**: Standardized interfaces allowing you to swap between OpenAI, Anthropic, Gemini, or local LLMs seamlessly.
- **`Agent` Abstraction**: Extendable base classes for building specialized, single-purpose AI workers (e.g., LeadScoringAgent, SupportAgent).
- **`Pipeline`**: Sequential event-processing for deterministic data transformations before or after AI reasoning.

## 💻 Quick Start Example

```typescript
import { Runtime, Agent } from "@agent-runtime/core";

const runtime = new Runtime();
runtime.use(new AnthropicProvider(process.env.API_KEY));

class LeadScoringAgent extends Agent {
  protected onStart(): void {
    this.bus.subscribe('lead.created', async (event) => {
      const score = await this.ai.analyze(event.payload);
      this.bus.publish({ type: 'lead.scored', payload: { score } });
    });
  }
}

runtime.register(new LeadScoringAgent());
runtime.start();

// Trigger the workflow
runtime.publish({ type: "lead.created", payload: { email: "ceo@example.com" } });
```
